# MAP2B databases

Pre-built and custom MAP2B databases are not bundled in this repository. Pre-built GTDB databases for BsaXI, BcgI, and CjePI can be downloaded with `software/map2b/scripts/DownloadDB.py` and the corresponding list under `software/map2b/config/`. See [`DATABASE_BUILDER.md`](../../../docs/01_Reference_database_construction/DATABASE_BUILDER.md) for the command.
